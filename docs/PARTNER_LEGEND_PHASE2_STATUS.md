# v0.2.0 구현 현황 — 2026-10-22

## 완료(소스 변경, 인게임 미검증)
- Partner Legend 칭호 12단계: 100 / 1k / 5k / 10k / 25k / 50k / 75k / 100k / 150k / 250k / 500k / 1M.
- F8: 칭호 수동 장착, 해제, 자동 선택, 이펙트 탭. 선택 칭호별 **2D 발밑 링 + 움직이는 광점 오오라** 렌더러 추가(기본 꺼짐).
- 캐릭터 ModData 사용. 구버전 칭호 배열은 기존 누적 처치 기록으로 재계산.
- 숙련: 근접 여섯 계열 및 단일 투사체 총기 10레벨 +1 / 20레벨 추가 +1 타격 한도.
- 적용은 무기 장착 시와 기존 1분 스탯 확인에서 갱신되며, 장착 해제 시 원상 복귀. 샷건(멀티 투사체) 제외. MaxHitCount >12 기존 무기는 수정하지 않음.
- 아공간 상점: 일반 가격 x2, 특성 200코어/점, 전설 뽑기 10k, 전체 수리 4k, 고정가 팩 가격 및 환불 일치.
- 전설 드랍/상점 풀 60 + 29 = 최대 89종. **전설 드랍은 무기 1종마다 보관함당 독립 1/10,000 판정**(전체 89종이 설치되어 있으면 보관함당 최소 1개 확률 약 0.8861%). 원본 신무기 드랍을 시작 시 1회 분포표에서 제거.

## 미구현(다음 단계)
- **베타 구현:** 전설 완제품 최초 조립 제작법 11개에 B42 soft override(OnTest=false, 전용 비활성 태그)를 적용. 제작 UI에서 완전히 숨겨지고 조립 불가능한지 인게임 검증 필요. 색상 변경·수리·재조립은 남김.
- 생존일지 전체 34종 + Partner 30종에 능력치·코어 보상 1회 지급. UI는 기존 파트너 29종 + 조준10 1종만 확장.
- F8 오오라 게임 내 위치·줌·HUD 호환성 검증 / 추가 자유 칭호 / 완성형 고유 장비.
- 모드 옵션에서 상점 배율 세부 설정 및 무료 지급/환불 검증.
- 89종 무기 가중치 밸런스(새 카타나 색상 20종이 당첨 가중치 20칸을 차지함).
- 무기 외부 모드 변경과 동시 강화시 전투 동작 시험.

## 설치/시험 주의
- 절대 원본 세이브를 먼저 실행하지 말고 복제 세이브로 시험.
- 새로 생성되는 보관함의 드랍만 바뀜. 기존 아이템은 제거하지 않음.
- 현재 스크립트는 싱글용이며 멀티플레이/서버 검증 전.
- 로드 권장: 원본 두 무기 모드 → PartnerLegendaryWeaponDrops, Daily Report Journal → Partner Legend → Partner Journal Extension.
- F8의 오오라 설정은 향후 렌더러가 추가될 때까지 외형 변화 없음.
- Journal의 기존 저장 일지와 Partner의 현재 처치/레벨 기준이 달라 훈장 해금 시점이 다를 수 있음.

## 2026-10-22 희귀도 해석 수정
- 과거 구현은 보관함당 단 한 번 1/10,000을 굴린 후 목록에서 무기 하나를 뽑았음.
- 사용자 요청에 맞춰 **무기별 독립 1/10,000**으로 변경. 여러 무기가 같은 보관함에 생성될 가능성을 그대로 유지함.
- 89종 무기 전부 유효하면 총합 기대값 89/10,000이고, 최소 1개 이상 발견 확률은 1-(9999/10000)^89 ≈ 0.8861%.
