# 공개 범위와 제외 항목

## 포함

- 우리가 직접 작성한 독립 Lua/Java 소스
- 우리가 빌드한 작은 런타임 JAR
- Partner 패치의 `mod.info`와 README
- Mod ID, Workshop ID, 버전, 로드 순서
- 테스트 결과와 알려진 제한
- 기준 세이브의 활성 모드 이름 목록

## 제외

- 세이브 파일과 캐릭터 데이터
- `console.txt`, 서버 로그, IP, Steam 식별자
- 로컬 절대 경로와 사용자 이름
- 백업 ZIP
- 창작마당에서 받은 원본 모드 전체
- 제작자가 개인적으로 공유한 `VSGirlBodyExtensionClothingCompatibility`
- Brita 원본 검증 스크립트의 파생 코드
- Fantasy Workshop 원본 FBX 별칭 파일
- 아공간 원본의 번역·자산

## 저장소 이용 방식

다음 작업자는 이 저장소의 문서와 코드를 읽고 현재 상태를 이해할 수 있습니다. 실제 설치 파일이 필요한 경우 로컬의 검증된 사본을 사용하거나, 원본 모드를 창작마당에서 설치한 뒤 Partner 코드만 별도로 적용해야 합니다.
