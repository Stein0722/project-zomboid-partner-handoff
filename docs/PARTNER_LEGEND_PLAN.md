# Partner Legend 기획안

## 목표

장기 싱글플레이에서 킬 수, 생존 일수, 스킬 레벨로 칭호와 훈장을 얻고 현재 캐릭터가 조금씩 강해지는 가벼운 업적 모드입니다.

## v0.1에서 구현할 것

### 칭호 12단계

| 킬 수 | 칭호 |
|---:|---|
| 100 | 첫 번째 피 |
| 1,000 | 좀비 사냥꾼 |
| 5,000 | 무리의 사냥꾼 |
| 10,000 | 베테랑 학살자 |
| 25,000 | 군단의 악몽 |
| 50,000 | 죽음의 집행자 |
| 100,000 | 인간 병기 |
| 250,000 | 종말의 집행자 |
| 500,000 | 재앙의 종결자 |
| 1,000,000 | 인류의 구원자 |
| 2,000,000 | 멸절자 |
| 5,000,000 | 최후의 심판자 |

### 훈장

- 생존: 7일, 30일, 100일, 365일, 1,000일
- 근접 숙련: 무기 계열별 10, 15, 20레벨
- 사격: 조준 15, 20레벨
- 관리: 정비 20레벨, 재장전 20레벨
- 전투: 10,000킬, 50,000킬, 500,000킬, 1,000,000킬
- v0.1 보상은 근접·총기·전체 무기 피해량과 무기 계열별 피해량 같은 단순 보너스부터 구현합니다.

### 모드 설정

사용자가 게임 안에서 직접 조절할 수 있어야 합니다.

- 칭호·훈장 요구 수치
- 각 훈장의 보상 수치
- 생존·숙련·전투 훈장 보상 배율
- 전체 보상 효율 0~200%
- 일반 피해 보너스 총합 상한(기본 제안 +20%)
- 각 훈장·보상 ON/OFF

설정을 바꾸면 훈장을 다시 지급하지 말고 최종 보너스만 다시 계산합니다.

## 저장·호환·성능 규칙

- 기존 세이브의 현재 킬·생존일·스킬을 읽어 달성한 업적을 소급 인정합니다.
- 훈장은 캐릭터별 `ModData`에 한 번만 기록하고 중복 보상을 막습니다.
- 여기서 영구 보상은 **현재 캐릭터가 살아 있는 동안**을 뜻합니다. 새 캐릭터 자동 상속은 기본적으로 없습니다.
- Skill Journal이 킬 수를 복구해도 이미 받은 훈장을 중복 지급하지 않습니다.
- 1~10레벨은 바닐라, 11~15는 Beyond Ten, 16~20은 `PartnerMasteryExtension.GetEffectiveLevel`을 우선 사용합니다.
- Traits As Skills에는 XP를 주거나 내부 데이터를 바꾸지 않고 필요할 때 조회만 합니다.
- 매 프레임 검사, 전체 좀비 검색, 별도 탄환 엔진, 공격 피해의 이중 판정을 만들지 않습니다.
- 저빈도 검사와 실제 킬·레벨 변화 때만 갱신합니다.
- Build 42 번역은 `common/media/lua/shared/Translate/KO/UI.json`과 EN JSON을 사용합니다.
