# 작업 연혁

이 문서는 대화 전체를 그대로 복사하지 않고, 실제 설정과 파일로 확인할 수 있는 결정만 요약합니다.

## 1. 무게와 멀티플레이

- 모든 아이템의 최종 운반 무게를 0.01배로 계산하는 Java/Lua 패치를 만들었습니다.
- 화면상 최대 무게와 실제 인벤토리 수납 한도를 맞췄습니다.
- 클라이언트에서는 되지만 협동 서버 검사에서 거절되던 이동을 고치기 위해 ZombieBuddy 협동 서버 브리지를 추가했습니다.
- 실제 무게가 낮은데도 남아 있던 Heavy Load 지구력 소모를 제거했습니다.
- Build 42 멀티 월드맵의 플레이어 표시와 안개 문제도 함께 보완했습니다.

## 2. RPG·특성·수면 구성 정리

- Project RPG에서 자동 경험치 증가, 화면 깜박임, 대량 오류가 발생해 현재 목록에서는 제외했습니다.
- 구 More Traits와 Definitive를 동시에 사용하지 않고, 현재는 More Traits Definitive + Traits As Skills + 전용 호환 모드 조합입니다.
- Sleep With Friends는 현재 목록에서 제거했습니다. 수면은 서버/싱글 기본 허용 설정을 사용합니다.

## 3. 아공간 멀티 및 상점 확장

- 친구가 다른 아공간에 갇히거나 공유 경계 밖으로 못 나가던 문제를 조사하고 공용 좌표·공용 업그레이드 구조로 변경했습니다.
- 치유의 성소 등 업그레이드가 자원만 먹고 반영되지 않던 문제를 수정했습니다.
- 상점 지갑은 플레이어별로 유지했습니다.
- 판매 품목, 가격, 기술서, 전설 무기 뽑기, 전체 수리, 호흡기 필터 제작을 확장했습니다.
- 판매 목록을 열 때 인벤토리를 반복 검색해 생기던 렉은 한 번의 검색과 짧은 캐시로 줄였습니다.
- 우물과 자동 줍기 4·5단계, 품목별 ON/OFF를 추가했습니다.

## 4. 성능과 로그

- 좀비·시체가 많을 때의 렉과 반복 오류를 로그로 추적했습니다.
- 인벤토리에 매우 많은 아이템을 들고 있으면 `ItemContainer.contains`와 Lua/UI 그리기 비용이 커지는 것을 F9 오버레이로 확인했습니다.
- PZ Optimization 권장 설정은 사용 중이지만, F9 화면 자체는 분석 오버레이여서 월드가 검게 가려질 수 있습니다.
- Viewpoint 계열은 VRAM/복잡도와 취향 문제로 현재 목록에서 제거했습니다.
- 대형 월드맵을 열었을 때 일시적으로 프레임이 떨어지지만 닫으면 회복되는 것을 확인했습니다.

## 5. 대형 지도와 대구

- 겹치는 Blackstone/Camden 계열 지도 대신 대구 지도를 선택했습니다.
- 대형 지도 조합에서 `map_meta.bin` 저장 버퍼가 넘치는 문제에 64 MiB 메타데이터 버퍼 패치를 추가했습니다.
- 이미 0바이트가 된 지도 메타데이터는 자동 복구되지 않으므로 새 지구나 정상 백업에서 시험해야 합니다.

## 6. 바디·의상·렌더링

- VSGirl Body Extension과 Tomb Body 환경을 맞추고, 기존 All-female 대용량 자산 대신 가벼운 여성 좀비 브리지를 만들었습니다.
- Fantasy Workshop `cat71` 모델명 불일치로 의상이 회색이 되는 문제를 별칭 모델로 우회했습니다.
- VSGirl 렌더 스레드가 착용 목록 변경 순간 예외로 멈추는 경로를 제한적으로 보호했습니다.
- 제작자가 공유한 `VSGirlBodyExtensionClothingCompatibility`는 로컬 외부 모드이며 이 저장소에 포함하지 않습니다.

## 7. 브리타와 총기

- 처음에는 방어구 팩만 있어 총기 스폰이 없었고, 이후 B42 통합 포팅 무기 팩을 추가했습니다.
- Brita Armor 1.4.9의 검증 오류를 버전 한정 호환 패치로 우회했습니다.
- Excalibar, Xixi, Final Fantasy 무기 60종을 보관함당 1/10,000 확률로 얻는 독립 드랍 풀을 만들었습니다.
- 바닐라와 브리타 총기의 역할·피해·관통·조작감, 사람에게 들리는 음량, 일체형 소음기를 조정하는 경량 탄도 모드를 만들었습니다.

## 8. Beyond Ten

- Beyond Ten 1.3.4가 바닐라 10레벨은 유지하고 별도 XP로 11~15를 계산하는 구조임을 확인했습니다.
- 현재 Skill Journal은 Beyond Ten XP를 모르므로 독립 브리지 v1.0.1을 만들었습니다.
- 첫 v1.0.0은 B42 Kahlua의 `next` 문제와 9→10 경계 처리 때문에 실패했고 v1.0.1에서 수정했습니다.
- 같은 특성 조건의 새 캐릭터로 일기장 복구를 시험해 기록자·일기장·복구 캐릭터의 긴둔기 마스터리 XP가 정확히 일치함을 확인했습니다.
- 복제 세이브 시험 통과 뒤 2026-10-21에 원본 세이브 전체 백업을 만들고 활성 목록에 적용했습니다. 첫 본세이브 실행 확인은 아직 남았습니다.

## 9. Partner Mastery Extension 16~20 베타

- 원본 Beyond Ten 1.3.4를 수정하거나 재배포하지 않는 독립 동반 모드 v0.2.1을 만들었습니다.
- 바닐라 1~10과 Beyond Ten 11~15는 그대로 두고 16~20 XP 저장과 보라색 스킬 칸 5개를 추가했습니다.
- Beyond Ten 상한은 평소 15로 유지하고 저장·표시 계산 순간에만 20을 사용합니다.
- v0.2.0부터 공통 숙련 랭크를 16~20에서 레벨당 0.5씩 더해 핵심 보너스를 50% 효율로 연장합니다.
- v0.2.1에서 Build 42 JSON 번역을 추가해 모드 설정 이름과 설명의 한글 표시를 고쳤습니다.
- 모드 설정에 0~150% 실시간 보너스 효율 슬라이더를 추가해 게임을 끄지 않고 다음 행동부터 조절할 수 있게 했습니다.
- 별도 `OnTick`, 좀비 검색, 공격·피격 이벤트를 추가하지 않았습니다.
- 브리지 1.1.0은 Extension이 있을 때 16~20 XP까지 기록·복구하고, 없으면 기존 11~15 동작을 유지합니다.
- Lua 구문 검사, 독립 계약 시험, 설치된 Beyond Ten 1.3.4 원본 소스 통합 시험을 통과했습니다.
- 보라색 20칸 UI는 복제 세이브에서 확인했습니다. 자연 16레벨 이후 보너스·재시작·사망 복구는 아직 실제 도달 전이며 v0.2.1은 싱글플레이 전용입니다.
