# Partner Journal Extension v0.1.0
Daily Report Journal(2858201402)의 훈장 탭에 Partner Legend의 29개 기존 훈장과 조준 10레벨 훈장 1개를 추가합니다.

- 기존 일지 UI, 해금된 날짜, 훈장 정렬을 재사용합니다.
- F8은 칭호 장착/해제/이펙트 설정 전용입니다.
- 루프 추가 없음. 게임 내 하루 종료 시 원본 checkMedals가 모든 확장 훈장을 판정합니다.
- 일지 원본은 수정하지 않습니다.
- 본 버전은 **훈장 UI/달성 조건 통합** 단계입니다. 코어·피로·허기 등 비피해 패시브 지급은 다음 단계입니다.
- 기존 Partner Legend 29개는 아직 이전 버전의 데미지 보너스 로직을 갖고 있습니다. 신규 계획과 혼동하면 안 됩니다.
- 사용: Daily Report Journal, Partner Legend 0.2.0, Partner Journal Extension을 모두 활성화.
- 게임 안에서 J > 훈장 탭에 추가 훈장 표시가 나타나는지 복제 세이브로 테스트하세요.
