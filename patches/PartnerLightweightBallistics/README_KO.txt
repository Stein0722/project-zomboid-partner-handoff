Partner Lightweight Realistic Ballistics v1.2.1

상태
- 코드 및 Lua 구문 검사는 완료했지만, B42.21 인게임 관통 검증 전인 베타 버전입니다.

목표
- 바닐라와 BritaCombinedB42의 총기·활·석궁·새총 역할과 화력을 가볍게 조정합니다.
- 바닐라/브리타/소음기 총소리를 각각 조절합니다.
- B42 기본 탄환과 관통 처리만 사용합니다.
- 별도 탄환 오브젝트, OnTick, 좀비 탐색, 발사 이벤트를 사용하지 않습니다.
- 브리타 B42 포팅판에서 일반 총성으로 잘못 지정된 일체형 소음기 총기를 고칩니다.

설정 위치
- 설정 > 모드 설정 > Partner 경량 탄도
- B42용 UI.json 번역을 포함해 설정 이름과 항목이 한글로 표시됩니다.
- 설정을 적용하면 현재 소지한 원거리 무기에 즉시 반영됩니다. 새로 얻은 무기는 소지하거나 장착할 때 반영됩니다.
- 분류별 관통 설정은 모든 프리셋에서 작동하며 조준경·소음기 등이 붙은 무기에도 적용됩니다.
- 같은 설정을 여러 번 적용해도 관통 대상 수가 계속 누적되지 않습니다.

기본 프리셋: 싱글 강력
- 9mm/.38 피해량 1.55배
- .45/.44/.357 피해량 1.60배
- 5.56 계열 피해량 1.65배
- .308/7.62 계열 피해량 1.70배
- 산탄 피해량 1.40배
- 명중률/치명타 확률 보강
- 조준 시간 20% 단축, 반동 지연 15% 단축
- 소총/DMR/저격총 관통 역할 강화
- 일반 샷건 퍼짐 1.15, 장총열 중절식 샷건 퍼짐 0.75

다른 프리셋
- 멀티 보수적: 피해량과 조작감은 원본, 역할별 관통과 샷건 퍼짐만 조정
- 원본 피해/관통: 총기 수치를 원본으로 복구하고 음량 설정만 사용
- 사용자 설정: 피해/명중/치명타/조준/반동/관통을 직접 조정

분류별 관통 설정
- 권총, 기관단총, 산탄총, 소총, 저격총, 기관총, 활, 석궁, 새총을 각각 조절합니다.
- B42 엔진 규칙상 뒤쪽 대상은 앞쪽 대상과 거의 일직선(각도 차이 1도 미만)에 있어야 맞습니다.
- 유탄·로켓·화염방사기처럼 별도 폭발/화염 처리를 쓰는 무기는 안전을 위해 제외합니다.
- B42 산탄 엔진은 펠릿의 첫 충돌에서 멈추므로, 산탄총만 명중 순간 뒤쪽의 좁은 직선 범위를 확인해 관통 대상을 보완합니다.
- 원래 산탄에 이미 맞은 대상은 제외하며, 뒤쪽 대상은 순서대로 85%씩 피해가 감소합니다.

총소리 기본값
- 바닐라 70%
- 브리타 40%
- 소음기 25%

중요: 음량과 좀비 청각은 서로 분리되어 있습니다.
- 음량 슬라이더는 사람의 스피커/헤드폰으로 들리는 크기만 바꿉니다.
- B42가 개별 음량을 실제로 사용하도록 고급 사운드 스위치를 자동으로 켭니다.
- 적용 뒤 엔진에서 되읽은 값이 일치한 소리만 성공으로 기록합니다.
- 음량 슬라이더 자체는 총기의 SoundRadius, SoundVolume, NoiseRange를 수정하지 않습니다.
- 따라서 일반 총기가 좀비를 끌어오는 거리와 기존 소음기의 유인 성능은 그대로입니다.

일체형 소음기 호환 수정
- M635SD, Sten MK2SD, SIX12SD의 일반 총성과 일반 소음 반경을 소음기 값으로 수정합니다.
- AS Val Fold와 KRISS 22 CRB Fold의 사라진 구형 소리 ID를 현재 소음기 소리로 교체합니다.
- 이 다섯 자루만 설명에 맞게 좀비 유인 범위가 줄어듭니다. 일반 총기의 좀비 청각은 바뀌지 않습니다.
- 원본 브리타 파일은 수정하지 않습니다.

성능
- 게임 시작과 설정 적용 때만 원거리 무기 정의를 계산합니다.
- 저장된 무기는 캐릭터 생성/장착 때 갱신합니다.
- 매 프레임 검사와 전체 좀비 검색이 없습니다.
- 산탄총이 실제로 명중한 순간에만 뒤쪽의 가까운 격자를 제한적으로 확인합니다.

적용 순서
- BritaCombinedB42보다 뒤에 불러오세요.

로그 확인
- console.txt에서 [PartnerLightweightBallistics]를 검색하세요.
- 정상 문구: advanced=true / verified sounds / No definition failures / Zombie hearing unchanged

제거
- 모드를 끄고 게임을 완전히 다시 실행하면 새로 불러온 총기는 원래 정의를 사용합니다.
- 문제 발생 시 적용 직전 백업 ZIP으로 복원할 수 있습니다.
