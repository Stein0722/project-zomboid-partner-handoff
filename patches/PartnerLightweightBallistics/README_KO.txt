Partner 통합 경량 탄도 + 샷건 관통 v1.3.0 (샷건 엔진 v0.3.0)
Project Zomboid B42.21 / 싱글플레이 시험판

■ 목적
경량 탄도 v1.2.0의 총기 프리셋·총소리·브리타 호환을 유지하면서,
샷건 v0.3.0의 바닐라 조준 보호형 관통을 한 모드와 한 설정창으로 합침.

■ 설치 - 중요
1. 세이브 전체 백업 / 복제 세이브에서 먼저 시험.
2. 기존 Zomboid/mods/PartnerLightweightBallistics 폴더를 백업 후 삭제.
3. 압축파일의 PartnerLightweightBallistics 폴더를 Zomboid/mods에 복사.
4. 기존 PartnerShotgunProjectiles 별도 모드는 활성화 해제하고, 가능하면 폴더도 별도 백업.
5. 모드 목록에서 PartnerLightweightBallistics (기존 ID)를 단 하나만 활성화.
6. 설정 → 모드 설정 → 'Partner 통합 탄도 · 샷건 관통' 한 화면에서 두 기능을 조절.
7. 게임 완전 종료/재시작 후 JS-2000으로 빨간 조준 원과 후방 관통 확인.

■ 설정 보존
경량 탄도 ModOptions ID와 기존 설정 키를 그대로 사용하므로 경량 탄도의 저장된 설정을
계승하도록 설계. 샷건 별도 모드의 저장 키는 서로 다른 등록 ID여서 자동 이전하지 않음.
통합판 샷건 초기값은: 활성화 ON, 궤적 ON, 시각 펠릿 상한 12, 관통 2,
확산 20도, 후방 피해 85%, 상세 로그 OFF (사용자가 최근 테스트한 화면 수치).
처음 실행 시 값이 원하는 설정인지 확인.

■ 통합과 성능
- 샷건이 0명중이던 구형 maxHitCount=0 / projectileCount=0 해킹을 사용하지 않음.
- 샷건은 바닐라 조준·기본 명중과 피해를 유지, 확인된 기본 명중의 뒤쪽에만 보너스.
- 샷건의 '분류별 기본 관통 보너스'는 완전히 제거해 두 관통 방식이 중복되지 않음.
- 경량 탄도의 중복 장착 이벤트를 하나로 병합하고 동일 수치 setter 재호출을 방지.
- 기존 게임 저장값의 구형 제로값 복구 기능은 v0.3.0에서 그대로 유지.
- 경량 탄도 프리셋 1의 일반 샷건 기본 피해/명중 강화는 v1.2.0의 원래 동작을 유지.
- 총기 볼륨 설정은 플레이어 귀에만 적용; 좀비 유인 거리는 별도로 보존.

■ 주의
- 이번 통합은 실제 게임 실행 테스트가 아니라 Lua 정적/모의 검증만 완료.
- 무기 해제 순간 0.2초 끊김은 다른 모드·엔진 원인일 수도 있어 사라졌다고 보증하지 않음.
- 모드 로드 시 오래된 standalone 두 개가 동시에 켜져 있으면 설정 중복 및 피해 중첩 위험.
- 설치 후 빨간 조준 표시 / 엎드린 좀비 / 실제 후방 관통 / 장착·해제 FPS를 확인.
- 모든 원본/백업 파일과 GitHub 기존 안정 버전은 변경하지 않음.
