Partner Shared Spatial Refuge + Personal Wallet 1.9.2

기능
- 협동 서버의 모든 플레이어가 첫 번째로 만들어진 아공간 하나를 함께 사용합니다.
- 아공간 좌표, 크기, 시설 업그레이드는 공유됩니다.
- 누가 업그레이드해도 접속 중인 모든 플레이어에게 새 시설과 경계를 즉시 동기화합니다.
- 아공간에서 원래 위치로 돌아가는 좌표는 플레이어마다 따로 유지됩니다.
- 공간 상점의 코어 잔액은 플레이어마다 따로 저장됩니다.
- 패치 적용 당시 공용 지갑 잔액을 개인 지갑의 시작 금액으로 복사합니다.
- 공간 상점의 돈다발 판매가는 50코어, 주식 증서 판매가는 200코어로 조정됩니다.
- B42.21 바닐라 귀걸이, 목걸이, 초커, 배꼽 장신구, 반지, 팔찌, 손목시계를 판매할 수 있습니다.
- B42.21 바닐라 안경·고글류, 속옷류, 지갑류를 개당 코어 1개로 판매할 수 있습니다.
- B42.21 바닐라 스타킹·타이츠 8종을 속옷과 함께 개당 코어 1개로 판매할 수 있습니다.
- 지갑을 판매하기 전에는 안의 내용물을 먼저 꺼내야 합니다.
- B42.21 바닐라 신용카드는 개당 코어 3개, 신분증은 개당 코어 1개로 판매할 수 있습니다.
- 일반 상점 구매 품목의 가격을 1.5배(소수점 올림)로 조정합니다.
- 판매 보상, 복권·새로고침 비용, 아공간 영구 업그레이드 비용은 변경하지 않습니다.
- 의료 카테고리에서 반면형 마스크 호흡기 1개와 필터 4개 세트를 정확히 100코어에 구매할 수 있습니다.
- 의료 카테고리에서 호흡기 필터 5개 보충팩을 정확히 60코어에 구매할 수 있습니다.
- 독서 확장 모드의 도끼·장둔기·단둔기·단검·창·달리기·조준시 발걸음·은밀한 움직임·조용한 발걸음·근력·체력 기술서 완전판 11종을 서적 탭에서 각각 150코어에 구매할 수 있습니다.
- 장비 탭에서 5,000코어로 Excalibar, Xixi 무기팩, FFVII 무기팩의 검증된 전설 무기 60종 중 하나를 무작위로 획득할 수 있습니다.
- 전설 무기 뽑기 기록은 캐릭터마다 저장되며, 이 뽑기에서 이미 획득한 무기는 다시 나오지 않습니다. 모든 무기를 뽑은 뒤 구매하면 5,000코어를 환불합니다.
- 장비 탭에서 2,000코어로 플레이어 소지품과 그 안의 가방에 든 손상 무기를 모두 완전히 수리할 수 있습니다.
- 전체 수리는 무기 내구도만 회복하며 탄약, 호흡기 필터, 배터리는 채우지 않습니다. 수리할 무기가 없으면 2,000코어를 환불합니다.
- B42.21의 깨진 태그 검색을 우회하여, 빈 반면형 마스크 1개와 호흡기 필터 1개를 필터 장착형 마스크 1개로 안전하게 교환하는 전용 제작법을 추가합니다.
- 제작이 성공할 때 마스크와 필터가 함께 교환되므로, 필터만 사라지고 마스크가 변하지 않는 현상을 막습니다.
- 장착 재료로 사용한 호흡기 필터의 남은 양을 결과 마스크에 그대로 이어받습니다. 새 필터는 가득 찬 상태로 장착됩니다.
- 이미 구매한 빈 반면형 마스크와 필터에도 적용되며, 필터를 다 쓴 뒤에도 다시 장착할 수 있습니다.
- 영어 언어로 실행 중인 친구에게도 아공간과 상점 문구를 한국어로 표시합니다.
- 서버의 수면 허용 옵션을 켜면 같은 아공간의 텐트에서 함께 잘 수 있습니다.
- 자동 코어 획득 중 좌표가 사라진 좀비·시체 컨테이너에 제거 패킷을 보내던 오류를 막습니다.
- 코어는 서버 권한으로 정상 이동하며, 플레이어 가방에 추가되는 동기화는 유지됩니다.
- 상점 구매 가격·코어 보관·일괄 판매 문구가 번역 인자를 잘못 요구하던 경고를 막습니다.
- 아공간 업그레이드 완료 문구가 번역되기 전에 잘못 호출되던 경고를 막습니다.
- 코어 자동 수집 업그레이드를 5단계까지 확장합니다.
- 코어 자동 수집 3단계는 스피커를 요구하지 않고 신비한 코어 36개만 사용합니다.
- 4단계(정확히 코어 500개)는 기존 2타일 범위에서 좀비 시체의 속옷·스타킹·타이츠를 자동으로 줍습니다.
- 5단계(정확히 코어 1,000개)는 현금·돈다발·증서·장신구·시계·안경·지갑·신용카드·신분증도 자동으로 줍습니다.
- 상점의 해당 판매 품목 상세 화면에서 품목별로 자동 줍기를 켜거나 끌 수 있습니다.
- 새로 해금된 자동 줍기는 기본적으로 켜지며, 선택 상태는 공용 아공간 데이터에 저장되고 멀티에서 공유됩니다.
- 자동 줍기는 플레이어가 걸어서 2타일 안에 접근한 좀비 시체에만 적용되며 바닥·상자 물품은 건드리지 않습니다.

안전 장치
- 원본 창작마당 파일과 기존의 다른 개인 아공간 데이터는 삭제하지 않습니다.
- 모드를 끄고 백업을 복원하면 패치 전 상태로 돌아갈 수 있습니다.

멀티플레이
- 호스트와 친구 모두 이 폴더를 Zomboid/mods에 설치해야 합니다.

v1.7.0
- 판매 품목 선택 시 인벤토리를 매 프레임·품목 종류마다 반복 검색하던 계산을 한 번의 검색과 0.75초 캐시로 최적화했습니다.
- 설치된 아공간 우물을 강화하는 3단계 업그레이드를 추가했습니다.
  1단계: 200 코어 / 하루 50L / 최대 500L
  2단계: 500 코어 / 하루 200L / 최대 1,500L
  3단계: 1,000 코어 / 하루 1,000L / 최대 3,000L
- 우물 단계는 기존 아공간 업그레이드 데이터에 저장되며, 현재 설치된 우물과 공유 아공간에 적용됩니다.
- 우물이 없거나 적용에 실패하면 업그레이드 거래가 완료되지 않아 코어가 소모되지 않습니다.

v1.8.0

- 자동 수집 대상은 현재 상점 판매 목록에서 읽으므로 판매 목록과 실제 줍기 목록이 서로 어긋나지 않습니다.
- 서버가 줍기와 설정 저장을 처리하고, 공용 아공간을 사용하는 접속자에게 설정을 동기화합니다.
