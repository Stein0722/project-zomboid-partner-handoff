Partner Mastery Extension 0.1.0

목표
- 바닐라 1~10레벨은 그대로 둡니다.
- Beyond Ten의 11~15레벨과 기존 보너스는 그대로 둡니다.
- 16~20레벨의 XP를 저장하고 스킬 창에 보라색 칸 5개로 표시합니다.
- 16~20레벨은 아직 추가 능력치를 주지 않습니다.

중요한 제한
- 이 첫 버전은 싱글플레이 전용입니다.
- Beyond Ten 1.3.4 / API 1 / Project Zomboid 42.21만 대상으로 합니다.
- 멀티플레이에서는 서버의 15레벨 저장 한도가 확장 XP를 다시 잘라낼 수 있으므로 사용하지 마세요.
- Traits As Skills에는 기존처럼 바닐라 최대 10레벨만 보이게 둡니다.

작동 방식
- Beyond Ten의 원본 파일은 수정하지 않습니다.
- 평상시 Beyond Ten 상한은 계속 15라서 기존 보너스가 16~20까지 커지지 않습니다.
- XP를 저장하거나 16~20 표시값을 계산하는 짧은 순간에만 저장 용량을 20으로 확장합니다.
- 별도 OnTick, 좀비 검색, 공격 이벤트를 추가하지 않습니다.

권장 모드 순서
1. BeyondTen
2. PartnerMasteryExtension
3. SkillJournal도 활성화
4. Beyond Ten, Extension, Skill Journal보다 아래에 PartnerBeyondTenSkillJournalBridge 1.1.0 이상

안전한 시험 순서
1. 원본 세이브를 백업합니다.
2. 복제 세이브에서 먼저 켭니다.
3. 15레벨 스킬에 XP를 더해 보라색 16레벨 칸이 차는지 봅니다.
4. 완전히 종료하고 다시 시작해 XP가 유지되는지 봅니다.
5. 일기장 기록, 사망, 새 캐릭터 복구 후 16~20 XP가 돌아오는지 확인합니다.
6. console.txt에서 PartnerMasteryExtension 오류가 없는지 확인합니다.

제거 시
- 16~20에 해당하는 초과 XP는 Beyond Ten 15레벨 바깥 값이라 원본 모드가 표시하거나 보너스로 쓰지 않습니다.
- 제거 전에 15레벨 이후 XP를 일기장에 기록해도 이 모드 없이는 초과분이 복구되지 않습니다.
- 안전을 위해 제거 전 세이브 백업을 권장합니다.
