Partner Mastery Extension 0.2.0

목표
- 바닐라 1~10레벨은 그대로 둡니다.
- Beyond Ten의 11~15레벨과 기존 보너스는 그대로 둡니다.
- 16~20레벨의 XP를 저장하고 스킬 창에 보라색 칸 5개로 표시합니다.
- 16~20레벨은 Beyond Ten의 핵심 숙련 랭크를 50% 효율로 이어갑니다.

중요한 제한
- 이 첫 버전은 싱글플레이 전용입니다.
- Beyond Ten 1.3.4 / API 1 / Project Zomboid 42.21만 대상으로 합니다.
- 멀티플레이에서는 서버의 15레벨 저장 한도가 확장 XP를 다시 잘라낼 수 있으므로 사용하지 마세요.
- Traits As Skills에는 기존처럼 바닐라 최대 10레벨만 보이게 둡니다.

작동 방식
- Beyond Ten의 원본 파일은 수정하지 않습니다.
- 평상시 Beyond Ten 상한은 계속 15라서 원본의 저장·UI 체계를 함부로 바꾸지 않습니다.
- XP를 저장하거나 16~20 표시값을 계산하는 짧은 순간에만 저장 용량을 20으로 확장합니다.
- 기존 보너스가 읽는 공통 숙련 랭크만 가중합니다. 15레벨은 5랭크, 16레벨은 5.5랭크, 20레벨은 7.5랭크입니다.
- 근접·총기 피해, 재장전, 정비, 지구력, 일반 작업 시간처럼 공통 숙련 랭크를 사용하는 핵심 효과가 이 값을 받습니다.
- 낚시 크기 표처럼 Beyond Ten 내부에서 레벨 15 전용 표를 사용하는 일부 특수 효과는 안전을 위해 15레벨 값에 머뭅니다.
- 별도 OnTick, 좀비 검색, 공격 이벤트를 추가하지 않습니다.

모드 설정
- 게임 설정 → 모드 설정 → 파트너 마스터리 확장에서 조절합니다.
- 추가 보너스 효율은 0~150%, 5% 단위이며 기본값은 50%입니다.
- 0%는 16~20 추가 보너스만 끄고 XP와 보라색 레벨은 유지합니다.
- 100%는 16~20을 11~15와 같은 세기로 계산합니다.
- 적용 버튼을 누르면 재시작 없이 다음 행동부터 새 값이 사용됩니다.

권장 모드 순서
1. BeyondTen
2. PartnerMasteryExtension
3. SkillJournal도 활성화
4. Beyond Ten, Extension, Skill Journal보다 아래에 PartnerBeyondTenSkillJournalBridge 1.1.0 이상

안전한 시험 순서
1. 원본 세이브를 백업합니다.
2. 복제 세이브에서 먼저 켭니다.
3. 자연스럽게 15레벨을 넘은 스킬에서 보라색 16레벨 칸이 차는지 봅니다.
4. 완전히 종료하고 다시 시작해 XP가 유지되는지 봅니다.
5. 일기장 기록, 사망, 새 캐릭터 복구 후 16~20 XP가 돌아오는지 확인합니다.
6. console.txt에서 PartnerMasteryExtension 오류가 없는지 확인합니다.

제거 시
- 16~20에 해당하는 초과 XP는 Beyond Ten 원본의 15레벨 바깥 값이라 이 동반 모드가 있어야 표시·보너스에 사용됩니다.
- 제거 전에 15레벨 이후 XP를 일기장에 기록해도 이 모드 없이는 초과분이 복구되지 않습니다.
- 안전을 위해 제거 전 세이브 백업을 권장합니다.
