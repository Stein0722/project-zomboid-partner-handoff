Partner All Weight 0.01x + MP Map Fix 2.6.0

대상 게임: Project Zomboid Build 42.21
필수 모드: ZombieBuddy

기능
- 바닐라와 모드 아이템의 최종 운반 무게를 0.01배로 계산합니다.
- 물, 기름, 탄약 및 모드 유체의 내용물도 최종 운반 무게에 포함한 뒤 0.01배로 계산합니다.
- 새 아이템뿐 아니라 세이브에 이미 존재하는 아이템에도 같은 계산을 사용합니다.
- 캐릭터 인벤토리의 숨은 약 50 제한을 화면에 표시되는 최대 무게와 일치시킵니다.
- 따라서 Project RPG나 특성이 최대 무게를 300으로 올리면 실제 수납 검사도 300을 사용합니다.
- 가방은 원래 용량을 유지하지만 수납 검사도 같은 0.01배 무게를 사용하므로 실질 수납량이 크게 늘어납니다.
- 협동 서버 프로세스에도 ZombieBuddy를 자동 연결하여 인벤토리 간 이동 검사를 클라이언트와 동일하게 만듭니다.
- 협동 서버가 만들어지기 전에 자동 연결 패치를 미리 불러옵니다. 캐릭터에서 가방으로 옮길 때 서버가 원래 무게로 거절하던 문제를 해결합니다.
- 무게가 0.01배인데도 남아 있던 과적 상태가 달리기 지구력을 최대 2.8배 더 소모하지 않도록 과적 페널티를 비활성화합니다.
- Build 42 멀티의 MapAllKnown 오류를 우회하여 월드맵의 안개 가리개를 끕니다.
- 월드맵의 본인/원격 플레이어 아이콘과 이름 표시를 항상 켭니다.

복구
- 모드 목록에서 Partner Dynamic Weight Compatibility를 끄면 됩니다.
- 저장된 원본 무게값을 바꾸지 않으므로 세이브 데이터 복구는 필요 없습니다.
