# Partner Legend v0.1.2 — 개인용 경량 베타

## 들어간 기능
- 칭호 12종, 훈장 29종(생존 5, 무기 숙련 18, 조준 2, 킬 4).
- 기존 세이브의 킬 수, 생존 일수, 스킬 레벨 소급 인정.
- 16~20레벨은 PartnerMasteryExtension.GetEffectiveLevel 이용, 기존 모드가 없으면 Beyond Ten/바닐라 조회.
- 훈장 보상은 근접, 총기, 모든 무기, 무기 계열 피해 보너스.
- 모드 설정: 전체·생존·숙련·전투 보상 배율, 훈장별 피해 보너스(0이면 OFF), 합계 상한, 킬·생존일수 요구 배율.
- 업적 확인 단축키 F8. 캐릭터 ModData 기록, 사망 시 새 캐릭터에게 자동 상속되지 않음.

## 성능·호환 설계
- 게임 내 1분에 1회만 기존 통계 확인. 전투 타격·좀비 사망·발사 이벤트, OnTick, 좀비 목록 순회 없음.
- 무기 정의를 수정하지 않고 주무기 인스턴스의 MinDamage/MaxDamage만 장착·설정 변경·훈장 해금 시 보정. 장비를 벗으면 직전 값 복원.
- 무기에 남긴 ModData 표식으로 재장착·재시작 시 배율이 반복 곱해지지 않도록 처리.
- 날을 갈 수 있는 무기는 B42의 날카로움 보정을 되돌려 원시 최대 피해를 저장하므로 재적용해도 피해가 겹치지 않음.
- 다른 모드가 장착 중 피해 값을 갱신했다면 장비를 다시 장착하거나 설정을 적용해서 새 수치에 맞춤.
- 다른 모드와의 경쟁을 최소화하려면 PartnerLightweightBallistics 뒤에 로드하는 것을 권장.
- 장착된 무기가 강화된 상태로 저장될 수 있으므로 **모드를 비활성화하기 전에는 무기를 해제한 후 저장**한다.
- B42.21 싱글플레이 전용. 무기 계열은 B42 무기 getPerk 기준이며 비표준 모드 무기는 계열 보너스를 못 받을 수 있음.

## 시험 순서
1. 원본 세이브 ZIP을 백업하고 복제 세이브에서 활성화.
2. F8 UI 열기와 스크롤·닫기, 12칭호/29훈장 확인.
3. 기존 킬/생존/스킬 업적의 소급 해금과 동일 업적 중복 방지.
4. 무기 장착/해제 시 MinDamage/MaxDamage 값과 탄도학 패치의 설정값 비교.
5. 설정 효율 0%/100%/200%, 요구 배율 변경, 재시작 후 값 보존 확인.
6. 사망·새 캐릭터에서 업적/강화 미상속 확인. console.txt 및 F9 성능 비교.

게임 내 실전 검증은 **아직 진행하지 않음**. 로컬 Codex에게 코드 검수·설치·복제 세이브 확인을 맡긴다.
