Partner Coop ZombieBuddy Bridge 1.0.0

대상 게임: Project Zomboid Build 42.21
필수 모드: ZombieBuddy

기능
- 메인 화면에서 먼저 로드됩니다.
- 게임의 '서버 열기' 버튼이 만드는 협동 서버에도 ZombieBuddy를 연결합니다.
- Partner All Weight 0.01x 모드가 서버의 인벤토리 이동 검사에도 적용되도록 합니다.
- 협동 서버의 가비지 컬렉터는 Java의 안전한 기본값을 사용합니다.

중요
- 이 모드는 기본 모드 목록에서 켜 두어야 합니다.
- 서버 설정의 Mods 목록에는 넣지 않습니다.
- 저장 데이터나 아이템의 원본 무게값을 수정하지 않습니다.

복구
- 기본 모드 목록에서 Partner Coop ZombieBuddy Bridge를 끄면 됩니다.
